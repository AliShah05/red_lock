# Изображения для каталога "Премиум-класс"

В этой папке должны находиться изображения для карточек товаров каталога замков премиум-класса.

## Список необходимых изображений:

1. **Замок "Премиум+"** - `1.png`
2. **Замок "Элит Премиум"** - `2.png`
3. **Замок "Люкс"** - `3.png`
4. **Замок "VIP"** - `4.png`
5. **Замок "Престиж Премиум"** - `5.png`
6. **Замок "Эксклюзив"** - `6.png`

## Формат изображений:
- Рекомендуемый размер: 400x400 пикселей
- Формат: PNG, JPG или JPEG
- Качество: высокое, четкое изображение замка
- Фон: нейтральный или прозрачный
