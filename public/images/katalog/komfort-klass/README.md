# Изображения для каталога "Комфорт-класс"

В этой папке должны находиться изображения для карточек товаров каталога замков комфорт-класса.

## Список необходимых изображений:

1. **Замок "Комфорт+"** - `1.png`
2. **Замок "Безопасность+"** - `2.png`
3. **Замок "Престиж"** - `3.png`
4. **Замок "Элит"** - `4.png`
5. **Замок "Стандарт+"** - `5.png`
6. **Замок "Комфорт Премиум"** - `6.png`

## Формат изображений:
- Рекомендуемый размер: 400x400 пикселей
- Формат: PNG, JPG или JPEG
- Качество: высокое, четкое изображение замка
- Фон: нейтральный или прозрачный
