# 📸 Папка для изображений проекта "Red Lock"

## 🎯 Назначение
Эта папка предназначена для хранения локальных изображений проекта.

## 📁 Структура
```
public/images/
├── README.md (этот файл)
├── hero/          # Изображения для главной страницы
├── services/      # Изображения для услуг
├── portfolio/     # Изображения портфолио
└── icons/         # Иконки и логотипы
```

## 🚀 Как добавить новое изображение

### 1. Поместите файл в соответствующую папку
### 2. Обновите ссылку в компоненте:
```tsx
// Вместо CDN ссылки используйте:
src="/images/[папка]/[имя_файла].[расширение]"

// Пример:
src="/images/services/milwaukee-drill-lock-repair.jpg"
```

### 3. Рекомендуемые форматы:
- **JPG/JPEG** - для фотографий
- **PNG** - для изображений с прозрачностью
- **WebP** - для современной оптимизации
- **SVG** - для векторной графики

### 4. Размеры изображений:
- **Hero секции**: 1920x1080px или больше
- **Карточки услуг**: 800x600px
- **Портфолио**: 1200x800px
- **Иконки**: 64x64px или 128x128px

## 🔧 Преимущества локального хранения
✅ Полный контроль над изображениями
✅ Быстрая загрузка
✅ Простота обновления
✅ Независимость от внешних сервисов

## 📝 Примечания
- Все изображения автоматически доступны по пути `/images/`
- Next.js автоматически оптимизирует изображения
- Используйте компонент `next/image` для лучшей производительности
