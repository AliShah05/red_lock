# Изображения для каталога "Броненакладки"

В этой папке должны находиться изображения для карточек товаров каталога "Броненакладки".

## Требуемые изображения:

1. `1.jpg` - ABUS (Ручки с бронезащитой)
2. `2.jpg` - Накладная броненакладка Apecs (Серия Basic, линия Simple)
3. `3.jpg` - Врезная броненакладка Apecs (Серия Protector Pro, линия Standart)
4. `4.jpg` - Накладная броненакладка Cisa (Защитная броня из цементированной азотированной стали)
5. `5.jpg` - Врезная броненакладка Cisa (Защитная броня из цементированной азотированной стали)
6. `6.jpg` - Перекодировочная накладка Cisa (Секретная накладка для шестисувальдных замков)
7. `7.jpg` - Накладная броненакладка Kale Kilit
8. `8.jpg` - Врезная броненакладка Kale Kilit
9. `9.jpg` - Врезная броненакладка Mottura (Серия Defender Top System)
10. `10.jpg` - Накладная броненакладка Mottura
11. `11.jpg` - Накладная броненакладка Mul-T-Lock (Защита врезного замка стандарта DIN)

## Формат изображений:
- Все изображения должны быть в формате JPG
- Рекомендуемое разрешение: минимум 400x400 пикселей
- Размер файла: не более 500KB для оптимальной загрузки

## Порядок размещения:
Изображения должны быть пронумерованы от 1 до 11 и размещены в слайдере слева направо в указанном порядке.

## Описание товаров:
Все броненакладки изготавливаются из сверхтвердых сплавов и значительно повышают взломоустойчивость замков. Рекомендуются в обязательном порядке для защиты цилиндровых механизмов.
